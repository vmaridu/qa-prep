# Markdown Tutorial

Markdown is a simple way to format text. It helps you write content that is easy to read and easy to convert into HTML.

## 1. Headings

Use `#` to create headings.

```markdown
# Heading 1
## Heading 2
### Heading 3
```

## 2. Bold and Italic

- Use `**bold**` for bold text.
- Use `*italic*` for italic text.
- Use `***bold and italic***` for both.

## 3. Lists

### Unordered list

```markdown
- Item 1
- Item 2
- Item 3
```

### Ordered list

```markdown
1. First item
2. Second item
3. Third item
```

## 4. Links

Use square brackets and parentheses to add a link.

```markdown
[Open Google](https://www.google.com)
```

## 5. Images

```markdown
![Alt text](image-url)
```

## 6. Code

Use backticks for short code.

```markdown
Use `print("Hello")` in Python.
```

For larger code blocks, use triple backticks.

```python
def greet():
    print("Hello")
```

## 7. Blockquotes

```markdown
> This is a quote.
```

## 8. Horizontal Rule

```markdown
---
```

## 9. Tables

```markdown
| Name | Age |
|------|-----|
| Alice | 25 |
| Bob | 30 |
```

## 10. Tips

- Keep your Markdown simple.
- Use headings to organize content.
- Preview your file to check the formatting.

Happy learning!
