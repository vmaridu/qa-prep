# 🧭 04 - UI & Framework Automation

## 📌 Overview

- UI automation validates user-facing workflows and interaction behavior.
- Frontend frameworks shape how modern applications are built and tested.

## 🌐 Selenium Basics

Example:

```java
WebDriver driver = new ChromeDriver();
driver.get("https://example.com");
System.out.println(driver.getTitle());
driver.quit();
```

## 🏗️ Scalable Automation Framework Design

- Separate test logic from page objects.
- Reuse utilities for waits, assertions, and reporting.
- Keep test data externalized.

## 🔁 Regression Suites

- Create recurring checks for critical business functions.
- Run smoke and regression suites in CI/CD.

## 🧠 Popular Frontend Frameworks

- React
- Angular
- Vue.js
- Next.js
- Svelte

Where they are commonly used:

- React → dashboards, enterprise SaaS applications
- Angular → large enterprise applications
- Vue → rapid UI development and smaller teams
- Next.js → SEO-friendly web apps and modern React apps
