# 🔒 09 - Security Testing

## 📌 Overview

- Security testing ensures applications are protected against common vulnerabilities.
- QA engineers should know the basics of authentication, authorization, input validation, and data protection.

## 🛡️ Key Areas

- Authentication and authorization
- Input validation
- Session management
- Sensitive data handling
- SQL injection and XSS checks

## 📚 Useful Standard

- OWASP Top 10

## ✅ Example Checks

- Try invalid input to see if the app crashes or exposes data.
- Check whether secrets are stored in logs or source code.
- Verify access control for admin-only features.
