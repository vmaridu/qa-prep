# ⚡ 08 - Performance Testing with JMeter

## 📌 Overview

- Performance testing checks how an application behaves under load.
- JMeter is a popular open-source tool for stress, load, and performance testing.

## 📈 JMeter Basics

- Create thread groups
- Add HTTP requests
- Use assertions and listeners
- Measure response time and throughput

## 🔍 Common Performance Terms

- Throughput
- Latency
- Error rate
- Concurrency
- TPS (transactions per second)

## ✅ Example Use Cases

- Test login endpoint under many concurrent users
- Measure response time for checkout flow
- Identify bottlenecks before production release
